\# Smart Dam Safety Monitoring and Early Warning System



An open-source IoT-based prototype that monitors reservoir water level, rate of water-level rise, seepage, structural tilt and vibration to provide explainable early warnings.



\## Project Status



Planning and initial setup.



\## Technology Stack



\- ESP32 with MicroPython

\- Python 3.12

\- Flask

\- SQLite

\- HTML, CSS and JavaScript

\- Chart.js

\- PySerial



\## Project Structure



\- `esp32/` - MicroPython and sensor code

\- `dashboard/` - Flask dashboard

\- `data/` - Sensor readings and database

\- `docs/` - Documentation and diagrams

\- `tests/` - Project tests

\- `model/` - Physical-model designs and photographs
